# דף נחיתה: רחל וויס

דף נחיתה סטטי ב-HTML, CSS ו-JavaScript נקיים, בלי ספריות ובלי שלב בנייה.
כדי לראות אותו מקומית מספיק לפתוח את `site/index.html` בדפדפן.

## מבנה הפרויקט

```
pictures/             התמונות המקוריות. לא עולות לרשת.
site/                 האתר עצמו. רק התיקייה הזו עולה לרשת.
  index.html          כל התוכן והטקסטים של הדף
  css/
    tokens.css        צבעים, גופנים ומרווחים
    base.css          איפוס וברירות מחדל
    components.css    כפתורים, כותרות, שדות טופס
    sections.css      עיצוב כל סקשן לפי הסדר
  js/
    config.js         הגדרות: כאן מדביקים את מפתח הטופס
    navigation.js     תפריט מובייל, לוגו בכותרת, סרגל תחתון
    reveal.js         אנימציית החשיפה בגלילה
    eligibility.js    הבדיקה המהירה
    contact-form.js   בדיקת הטופס ושליחתו
  images/             לוגו, אייקון ותמונות מוכנים לאתר
```

## איפה משנים מה

| רוצים לשנות | הקובץ |
| --- | --- |
| טקסט באתר | `site/index.html` |
| צבע או גופן בכל האתר | `site/css/tokens.css` |
| מספר טלפון או מייל | `site/index.html` (חיפוש והחלפה של כל המופעים), וגם `fallbackPhone` ב-`site/js/config.js` |

## חיבור הטופס למייל (חד-פעמי)

1. נכנסים ל-https://web3forms.com ומזינים את `rw6701463@gmail.com` בשדה ליצירת מפתח.
2. המפתח מגיע למייל של רחל.
3. מדביקים אותו בקובץ `site/js/config.js`, בשורה `web3formsAccessKey: ''`, בין הגרשיים.
4. מעלים את האתר ושולחים פנייה לבדיקה. כדאי לבדוק גם בתיקיית הספאם.

עד שהמפתח מודבק, הטופס מציג הודעת שגיאה עם מספר הטלפון ולא שולח דבר.

## העלאה לרשת

1. נכנסים ל-https://app.netlify.com/drop ונרשמים בחינם.
2. גוררים לדף את התיקייה `site` בלבד, ולא את התיקייה הראשית.
3. מקבלים כתובת חיה. אפשר לשנות אותה בהגדרות האתר, ולחבר דומיין פרטי תחת Domain management.

בכל שינוי עתידי גוררים שוב את התיקייה `site` תחת Deploys באתר.
